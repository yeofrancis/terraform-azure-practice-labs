# Roadmap

This roadmap outlines the intended progression of the Terraform Azure Practice Labs.

## Phase 1 – Foundations
- [ ] Repository scaffolding
- [ ] Terraform CLI basics
- [ ] Core language syntax
- [ ] Providers, settings, and lock files
- [ ] Resource lifecycle and meta-arguments

## Phase 2 – State & Structure
- [ ] Variables, outputs, and locals
- [ ] Loops with count and for_each
- [ ] Data sources
- [ ] Remote state and backend configuration
- [ ] Environment strategies (workspaces vs folders)

## Phase 3 – Modularity & Reuse
- [ ] Local modules
- [ ] Public module usage
- [ ] Refactor capstone to modules
- [ ] Naming and standards module

## Phase 4 – Advanced Terraform
- [ ] Dynamic blocks
- [ ] Provisioners and external data
- [ ] State import and refactoring with moved blocks
- [ ] Debugging and state inspection

## Phase 5 – Capstone
- [ ] Platform baseline (networking + shared services)
- [ ] Workload infrastructure
- [ ] Multi-environment support (dev/uat/prod)
- [ ] Remote state integration between platform and workload

This roadmap may evolve as the project grows.
